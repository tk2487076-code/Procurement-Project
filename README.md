#Procurement and Vendor Management System

A data-driven project designed to streamline procurement workflows, analyze vendor financial quotations, manage an approved supplier database, and track individual purchase orders. 

#Project Overview

This repository contains a comprehensive data model for managing end-to-end procurement processes. It features dynamic vendor profiling, financial comparisons across multiple bidders, item-level purchase order tracking, and high-level analytical summaries to drive strategic sourcing decisions. 

#Data Structure

The project dataset is divided into five core operational segments: 

Vendor Database: A centralized registry tracking approved suppliers, contact details, material specialization, location, and GSTIN numbers.
Vendor Quotation Comparison: A granular pricing comparison sheet mapping quantities, unit rates, and totals across multiple competing vendors.
Purchase Orders: An itemized ledger detailing structured distribution of quantities and commercial agreements finalized per vendor.
Pivot Table Analytics: An aggregated financial layout summarizing the exact monetary allocation by product category across all suppliers.
Vendor Quotation Summary: A high-level decision matrix highlighting overall quotation amounts, project durations, and credit terms.

#How to Use

1. Clone this repository locally.
2. Open the primary data file in Microsoft Excel or your preferred data analysis tool.
3. Utilize the Pivot Table view to filter data by specific vendor or item descriptions for real-time commercial tracking.
